# QonaqÚı — Hotel Rating

Веб-приложение для поиска отелей и просмотра отзывов гостей. В проекте есть демо-каталог с моковыми данными и гостевой режим, позволяющий оставлять отзывы без настройки backend.

## Demo version

Демо-версия проекта: https://frontend-hotel-rating-website-44s08v8zb-co-t3.vercel.app

## Возможности

- просмотр демо-отелей в Алматы и Астане;
- поиск и сортировка отелей по цене, рейтингу и дате добавления;
- просмотр фотографий, описаний, адресов, рейтингов и отзывов отеля;
- гостевой вход без регистрации и backend;
- создание и удаление отзыва с оценкой от 1 до 5;
- сохранение демо-отзывов в браузере;
- адаптивный интерфейс и просмотр фотографий в слайдере.

## Демо-режим

1. Откройте страницу **Sign in**.
2. Нажмите **Continue as demo guest**.
3. Выберите отель и откройте раздел отзывов, чтобы добавить свой отзыв.

Демо-сессия действует до закрытия вкладки браузера. Новые отзывы сохраняются в браузере и остаются доступными после обновления страницы в том же браузере.

## Запуск локально

Требуется Node.js и npm.

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

3. Откройте адрес, указанный Vite в терминале (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

Для локального просмотра production-сборки:

```bash
npm run preview
```

## Деплой на Vercel

Проект собирается командой `npm run build`. Файл `vercel.json` содержит rewrite на `index.html`, чтобы прямое открытие и обновление SPA-маршрутов не приводило к ошибке 404.

Гостевой режим и демо-отели не требуют backend. Обычная регистрация и вход через API требуют доступного backend-сервера.
